# MiniMind-Lab 简历项目介绍

## 三条标准版：大模型算法工程师

**MiniMind-Lab｜小参数语言模型全流程训练与后训练对照实验**

基于MiniMind构建64M中文语言模型实验平台，在NVIDIA L20上完成数据构建、预训练、SFT及多种后训练实验，研究能力变化、通用能力保持与训练成本。

- **数据与监督训练：** 搭建预训练及指令数据清洗、去重、划分与版本追溯流程，完成预训练和多轮SFT迭代；围绕对话与指令遵循构建定向数据，最终S10在完整IFEval上取得18.48% prompt-level strict通过率（原生评测协议）。
- **后训练与扩展对照：** 完成Full FT/LoRA、DPO、GRPO/CISPO、Agentic RL、Dense/MoE及Qwen3-8B教师答案蒸馏实验；记录并分析离线目标与生成质量脱节、奖励投机、能力回退等问题，而非只报告训练loss。
- **评测与工程复现：** 建立7项通用benchmark（29,638题）、IFEval（541题）和Chat/Tool规则检查体系，实现八卡请求分片评测、覆盖与结果完整性校验、SwanLab跟踪，沉淀配置、数据指纹、权重校验及阶段报告。

## 证据与表述边界

- 证据入口：[最终报告](final_report.md)、[Phase8报告](phases/phase8-distill.md)。
- 上游模型架构与基础代码来自MiniMind；个人工作是实验设计、数据管线、训练/评测适配、故障修复与结果分析，不声称从零原创全部算法。
- 白盒token-KL蒸馏、OPD未实施；PPO不在本版已完成列表中。
- 蒸馏K02未提升：IFEval14.60%低于S10的18.48%，新约束集44.92%低于93.36%，不替换S10。
- 不把GRPO/CISPO的答案位置投机写作数学能力提升，不把DPO的离线偏好分数增长写作生成质量改善。
- Chat/Tool为小规模规则检查，不能等同大规模通用对话或真实生产Agent验收。
- 单seed、不同阶段评测适配器差异及任务家族复用需在面试中说明。
